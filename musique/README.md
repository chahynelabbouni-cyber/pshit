# Maison Chahyn

Le lecteur de musique personnel de Chahyn : noir & or, sans pub, hors connexion.

## Ce qu'il y a dedans
- **Ta musique** : import de fichiers ou dossiers (MP3, M4A, FLAC, OGG, WAV…), lecture des titres, artistes, albums, pochettes.
- **Accueil** personnalisé (« Bonsoir, Chahyn »), recherche, bibliothèque, titres likés, playlists.
- **Lecteur plein écran** : fond tiré de la pochette (flou + couleurs), visualiseur doré, glisser la pochette pour changer de titre, fondu enchaîné entre morceaux.
- **Paroles synchronisées** : lues dans tes fichiers (tags ou .lrc du même nom), sinon trouvées en ligne (LRCLIB, gratuit). La ligne en cours s'allume, on peut toucher une ligne pour y sauter.
- **Le Concierge (IA)** : analyse chaque titre (tempo, énergie), apprend ce que tu écoutes et à quelle heure, et compose tes playlists : école, sport, chill, soirée, nuit, mix du moment… Tu peux lui écrire ce que tu veux (« une playlist pour réviser 1h », « lance un truc pour la muscu »).
  - Fonctionne sans internet ni compte.
  - Option : ajoute ta clé API Claude (Réglages) pour qu'il comprenne n'importe quelle demande.

## Installer sur le téléphone
1. Mettre le dossier `musique/` en ligne une fois en HTTPS (GitHub Pages : Settings → Pages → branche `main`, dossier `/`).
2. Ouvrir `https://<utilisateur>.github.io/<dépôt>/musique/` sur le téléphone.
3. Android (Chrome) : ⋮ → « Installer l'application ». iPhone (Safari) : Partager → « Sur l'écran d'accueil ».
4. Ouvrir Maison Chahyn → importer ta musique.

La musique reste uniquement sur le téléphone.
